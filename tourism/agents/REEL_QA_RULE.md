# Правило для агентов рилсов (reel-qa, post-writer, smm-publisher, publisher)

Перед любой публикацией и перед передачей текста на одобрение:
1. Сохрани текст (подпись, сценарий, SRT) в файл.
2. Запусти: `python3 tourism/facts/check_facts.py файл`
3. Код выхода 0: можно показать Никите. 1: есть ошибки, исправь и повтори, не публиковать. 2: расхождения между документами, остановиться и спросить Никиту.
4. Цены, даты, коды и ссылки берутся только из `tourism/facts/facts.json`. Нет в таблице: спросить, не придумывать.
5. После субтитров прогнать проверку и по SRT (лимит 6 слов в реплике).
Публикует только Никита или Metricool после его «да».
